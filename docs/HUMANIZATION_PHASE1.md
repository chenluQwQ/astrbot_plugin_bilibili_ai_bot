# BiliBot 拟人化第一阶段总清单

本清单来自项目作者确认的“拟人化优化：第一阶段需求”，是开发顺序与验收状态的权威索引。
实现时以记忆连续性和自然互动为优先，不为了少量存储或 Token 破坏 Bot 的经历感。

## 项目约定

- 不一次性推翻现有实现；按阶段提交、测试和回滚。
- 不擅自改写核心人设，只维护有边界的近期状态、喜好与反思。
- 正常沉默、模型失败与发送失败必须分开处理；发送失败不能提交记忆、亲密度或计数。
- 用户已确认视频详细记忆使用 **15 天**，不是原建议的 30 天。
- 三个月后保留极低权重短摘要向量，使 Bot 偶尔模糊想起；永久 BV 账本独立负责绝不把旧视频当新视频。

## 阶段 1：严格输出协议与内部反馈

- [x] 评论、B站私信与直播回复统一为经过 Schema 校验的结构化结果。
- [x] `reply` 是唯一允许发送的文本，`signals`、JSON、内部标签和残缺输出永不外泄。
- [x] 无效或截断输出不回复，且不更新记忆、亲密度和互动计数。
- [x] 区分 `reply`、`ignore`、`observe` 和模型失败。
- [x] 反馈分类结合关系与上下文；建议只在回复成功后成为候选反思，主人建议权重为普通用户的 3 倍。
- [x] 反思候选按当前话题召回；只有主人提出、多人重复或累计权重足够的相关候选才参与表达，不把单条普通意见直接写进人格。
- [x] 覆盖残缺 JSON、signals 泄漏、发送失败不提交状态、事件幂等、熟人调侃和反馈权重测试。

## 阶段 2：永久 BV 去重与三层视频记忆

- [x] 新增无容量和时间裁剪的 SQLite `seen_videos` 永久账本；BV 本身不向量化。
- [x] `seen_videos.json` 作为无上限恢复副本，不再依赖最多 200 条的活动流水。
- [x] 从旧观看流水、评论记录、视频缓存、主动看片详情及视频语义记忆幂等迁移。
- [x] 自动看片、特别关注、私信看片和评论视频分析统一写入并查询永久账本。
- [x] 15 天内保留较完整的视频分析、感想与向量。
- [x] 15 天后降低检索和推荐权重；90 天后压缩为极低权重的“看过及大概内容”短摘要向量。
- [x] 只有主人在 B站私信中明确要求重新看时才允许重新分析。
- [x] 覆盖超过 200 条仍去重、重启持久化、旧数据幂等迁移、缓存复用和生命周期测试。
- [x] 把评分理由、喜好信号和搜索关键词补全到长期视频经历字段（进入阶段 3）。

## 阶段 3：视频评分、偏好信号与向量检索

- [x] 评分一次严格返回分数、理由、情绪、感想、分区、喜好信号和搜索关键词。
- [x] 评分读取当前人设、状态、已有喜恶、疲劳倾向和视频内容，避免“客观好片都高分”。
- [x] 分开提取 UP、分区、作品、人物、食物、主题等最多 5 个具体信号。
- [x] 检查向量去重、阈值、错召回和过期索引；Embedding 不可用时安全降级。
- [x] 视频经历已验证进入向量库并能语义召回，且具体信号已进入搜索选片；日报与周报接入留在阶段 4。

## 阶段 4：日报、周报与偏好生命周期

- [x] 日报分为自然语言报告和系统结构化摘要。
- [x] 结构化摘要显式统计高分视频、常见高分分区/UP、心情分布、具体偏好信号与搜索关键词。
- [x] 周报基于每日结构化摘要生成，不重复灌入全部原始视频。
- [x] 候选喜好一周、多次证据升级近期喜好、连续多周升级稳定喜好。
- [x] 每周支持增强、保留、减弱、删除以及负向偏好/审美疲劳。
- [x] 主动搜索真正使用近期兴趣、UP、分区、作品和情绪，同时保留探索概率。
- [x] 改善周报、推荐语、评论和私信的机械表达。

## 阶段 5：人格演变与梗学习

- [x] 人格演变改为每周一次，只更新有长度限制且可回滚的动态区块。
- [x] 反思只来自真实错误、明确纠正或重复反馈，不因单次事件剧烈改人格。
- [x] 每周提取少量梗候选，合并同义、达到阈值后再查询，最多保留 0～2 个并设有效期。
- [x] 梗只作为低频近期表达习惯，不进入核心人格。
- [ ] 在实际实例安装本阶段版本后，用 `/bili性格` 审阅首轮预备证据，再决定是否开启两个实验开关。

## 阶段 6：主动行为与互动数量

- [x] 评论和私信只保留安全上限，不设置必须完成的最低数量。
- [x] 拆分每天浏览窗口、每次视频数、每日总观看数、每日主动评论数及单视频评论数。
- [x] 动态优先由明显情绪、特别喜欢的视频、周总结或特殊经历触发，不按 KPI 强发。
- [x] 数量范围只作为安全预算，不强迫用完。

## 阶段 7：推荐文案与整体拟人化

- [x] 推荐、评论、私信都服从人设，去除客服腔、报告腔和机械画像引用。
- [x] 允许短回复、犹豫、沉默和不完整表达，避免为了活泼滥用语气词。
- [x] 推荐像“刚看完想到你所以顺手分享”，不必每次完整解释理由。

## 仍需持续满足的兼容与测试

- [x] 新增配置有合理默认值，说明与代码一致，并持续检测 JSON 重复键。
- [x] 旧数据不静默删除；迁移可校验、可降级，失败不要求用户清空 `data`。
- [x] 主动浏览次数、观看数量和评论数量分别生效。
- [x] 每个阶段交付时记录：改了什么、原因、数据兼容性、新测试、风险和未完成项。

## 阶段交付记录（2026-08-21）

- 输出与反馈：评论、私信、直播回复采用严格 Schema；发送成功后才提交反馈候选。旧回复日志和记忆原样兼容。
- 视频经历：新增永久 BV 账本与 15/90 天分层记忆；补全评分理由、偏好信号和搜索关键词，旧 JSON 只迁移不删除。
- 日报与偏好：日报同时保存自然语言和结构化摘要，周报组合每日摘要；新增偏好证据/状态表和轻量 JSON 副本。
- 主动行为：旧下限与固定回复目标保留为废弃兼容字段，但运行时不再读取；浏览轮次、每轮视频数、全天视频数、单视频评论数和全天主动评论数独立生效，模型失败不会自动填满日程。
- 自然表达：主动评论、给主人分享和动态均允许明确 `skip`，无效结构不发送，也不再使用万能兜底句。
- 收尾审计：修正长期视频记忆在配置键缺失时被部分入口误判为关闭的问题；新增有门槛、按话题召回的候选反思，并补全高分分区/UP与心情聚合。
- 安全演化：替换旧版每日读取原始记忆的演化流程；新版只在每周固定时刻读取最多 7 天结构化日报（没有归档日报时从活动日志派生隐私过滤结构）、周报、偏好及合格反馈，至少 3 个真实活动日才允许调用模型。自动结果只替换有限动态区块，保存 12 个回滚快照，失败后本周不再重复申请。
- 梗学习：候选必须有至少两条能在输入证据中找到的片段；可用 Embedding 时按向量合并同义表达，达到门槛后才联网核验。活动梗总数最多 2 个、7～30 天过期，并通过稳定散列仅在约 15% 的回复上下文中作为可选提示出现。
- 测试：182 项全部通过，覆盖协议泄漏、发送失败不提交、永久去重、视频召回、兴趣状态查看、Web 兴趣缓存/熔断/安全限长、反馈召回门槛、偏好升级/衰减、结构化周报、从旧活动日志安全派生日结构、每周演化门禁与幂等、回滚、反思证据约束、梗证据/合并/低频过期、上限语义、数量分离和动态沉默。
- 待完成：用运行实例的真实数据做只读预检后，已识别出 5 个近期活动日（门槛为 3 天）；但实例尚未安装包含新门禁的版本，`ENABLE_PERSONALITY_EVOLUTION` 与 `ENABLE_MEME_LEARNING` 继续保持关闭。安装后先用 `/bili性格` 查看证据准备状态，再决定是否启用。
