# 分镜宫格的文字与时间保护

开启已有的 `VIDEO_STORYBOARD_ENABLED` 后，截帧分析按时间挑选最多九帧。关闭后使用原来的逐帧回退。视频直读不经过这条处理链路。

默认九宫格的普通画面为 **720×400**。任意代表帧检测到至少两行文字时，保留 **1080×600**，以免漏掉菜单中的小字。这两个尺寸对应默认三列、三行，每格 360×200；自定义宫格不会被放大到默认尺寸。

先从视频抽取原尺寸代表帧，再生成宫格。预计缩图后不足十像素高的文字行，可以从这些原帧直接裁切，最多四处，按顺序排列成一张不超过 720×200 的补充图。每处标注对应的宫格编号，时间沿用该帧的时间码。顶部、底部字幕保留整行，以免检测不全而漏掉句首、句尾。裁切不缩放、不放大，不从缩小后的宫格取图；任一必要裁切超出空间或数量上限时，整个宫格保留原尺寸。文字密集画面只有在大图仍会缩小高清源帧时才补裁切，低清源已经按原像素呈现时不加重复补图。

缩图决策使用 Pillow 和 numpy 的局部对比度、连通笔画及行排列，不依赖 OCR 文字含义。左上角极小水印不参与尺寸决策。缺 numpy、原帧抽取失败或无法完成检测时，保留原尺寸；某一帧抽取失败在原位置回退，后面的画面不会移到它的时间码。

文字记录使用 `storyboard_text.py` 的本地 RapidOCR。每张原帧按 2 倍和 3 倍尺寸识别，再对检测到的字行从原帧裁切复核。两次裁切读出的文字必须一致，置信度都不低于 **0.95**，且至少一次同位置的整帧识别支持这个原文。只保存该整帧原文，不用模型或固定词典修字。缩放是 OCR 预处理，不能恢复源视频丢失的笔画。每行最多 160 字、每帧最多 900 字；超出预算的帧明确拒识，不默默截断文字。

宫格、可选文字图和按帧编号列出的 OCR 原文在同一次视觉请求中传入。文字按不可信视频素材隔离。模型的分镜输出只含 `frame_id` 与 `visual`，不输出秒数、不重写字幕。`parse_storyboard_watch` 验证帧编号并直接映射 `selected_timestamps + 片段起点`；OCR 原文独立添加到原帧时间，即使模型省略该帧，也不会把它移到别的时间。模型在画面描述中引用字幕或文字标签时，移除含引用的句子，保留独立的画面动作句；没有可保留的画面句时提示查看本地 OCR。视觉输出的 `audio` 固定为“听不到”。视频直读和关闭分镜后的逐帧仍使用原协议。

缺 OCR 依赖、缺原帧、识别报错、置信度不足或复核不一致时，文字记为“无法可靠辨认”，画面分析仍继续。`partial` 表示该帧有些字已确认、有些字拒识。引擎延迟加载、串行复用，并限制两个计算线程；不会额外调用收费 OCR API。请求完成后清理原帧、密集采样帧、宫格和裁切。

安装插件依赖即可启用 OCR：`rapidocr_onnxruntime==1.4.4`、`onnxruntime==1.23.2`、`opencv-python==4.11.0.86`，支持本插件的 Python 3.10–3.12 环境。更新已有插件时，在 AstrBot 实际使用的 Python 环境执行 `python -m pip install -r requirements.txt`，然后重载插件或重启 AstrBot。已有的分镜开关不变，无需迁移其他配置；缺失该开关时采用默认开启。Python 3.13 及以上跳过这三项依赖，文字按缺 OCR 处理。依赖安装失败不会让模型接管字幕猜测。

置信度和重复识别并不能证明所有文字都正确，低清、艺术字仍可能误读或漏检。采样秒数是该帧出现的时刻，不是字幕精确开始/结束时间；九帧之间的文字仍可能遗漏。额外文字图和 OCR 原文会增加输入 token，本地 OCR 会增加 CPU、内存及等待时间，文字较多的视频可能没有节省。以对应模型实际 `usage` 和固定真值复测为准，拒识应单独统计。
