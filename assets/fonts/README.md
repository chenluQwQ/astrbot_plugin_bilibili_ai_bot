# Bundled fallback font

`NotoSansSC-VF.otf` is the Simplified Chinese subset variable OTF from the
[Noto CJK project](https://github.com/notofonts/noto-cjk):

- Source: `Sans/Variable/OTF/Subset/NotoSansSC-VF.otf`
- License: SIL Open Font License 1.1; see `OFL.txt` in this directory
- SHA-256: `D13ED01EC8AA45D6178999B648E96FB92150683E9F8E2A581F2ACF208DCBE44B`

It is used only when the host system has no usable Chinese font. It must not be
treated as Python code or loaded from an untrusted runtime path.
