# Third-party visual assets

The interface uses adapted SVG paths from **Nieobie/Game-Icon-Pack**.

- Source: https://github.com/Nieobie/Game-Icon-Pack
- License: CC0 1.0 Universal
- Local use: `pages/bilibot/icons.js`

The paths are embedded as inline SVG so they can inherit the interface color tokens and remain crisp at every density.
